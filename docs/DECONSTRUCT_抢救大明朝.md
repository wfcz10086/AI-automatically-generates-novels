# 拆《抢救大明朝》：与《大宋有种》求公因式

读的是 `/opt/《抢救大明朝》（校对版全本）作者：大罗罗.txt`（gb18030）。**2278 章，574.9 万字**，均章 2523 字、中位 2505、最短 1862、最长 3782 —— 章长方差极小。

同一个作者的两本书摆在一起，才能把**框架**和**种子**切开：
> 两本共有的 = 该固化进生产线；两本不同的 = 该留给种子。

配套文档：[`DECONSTRUCT_大宋有种.md`](DECONSTRUCT_大宋有种.md)。

---

## 一、作品简介本身就是引擎说明书

```
朱慈烺此贼比汉奸还奸，比额李自成还能蛊惑人心！   ——李自成
慈烺此子忤逆不孝，奸诈凶残，简直是曹操再世……   ——崇祯
我冤枉啊！我洪承畴真的不是朱贼慈烺的内应！        ——洪承畴（刑场上）
父皇别跑，儿臣孝顺！                              ——朱慈烺（拎着剑追崇祯时的真心话）
```

**四段里三段是敌人对主角的错误评价，最后一段才是主角自己。** 这不是文案技巧，这是这本书的引擎被压缩成了四行：
- 李自成骂他「比汉奸还奸」—— 因为主角在利用汉奸
- 崇祯骂他「忤逆不孝」—— 因为主角追着他跑还喊「儿臣孝顺」
- 洪承畴喊冤 —— 因为主角把他**陷害成了自己人**，清廷信了

对照《大宋有种》的简介：铺的是背景+局势+主角登场，没有这四段。**这本更进了一步，直接把「别人怎么误读主角」当卖点。**

值得注意：两本的核心台词几乎一模一样 ——
- 大宋：「父皇别跑，儿臣**有种**！」
- 大明：「父皇别跑，儿臣**孝顺**！」

同一个反直觉动作（**追着要跑的父皇，不是为了夺位，是为了不让他跑**），换个朝代复用。这不是偷懒，这是作者自己找到的**可复用种子模板**。

## 二、两本的公因式（→ 该进框架）

### 2.1 文体指标：几乎完全一致

| 指标 | 大宋有种 | 抢救大明朝 |
|---|---|---|
| 对白占正文比 | 22% | 25% |
| 每千字问号 | 5.3 | 5.5 |
| 每千字叹号 | 9.5 | 8.8 |
| 段落数 / 章 | 56 | 45 |
| 段落平均字数 | 49 | 47 |
| 解说体（所谓/其实/这就是…）/ 章 | 1.8 | 1.4 |
| 史实回望（历史上/后世/前世）/ 章 | 0.5 | 0.4 |

**两本独立统计、数值咬合到这个程度，说明这些不是风格偏好，是可校准的硬指标。**
可以直接做成 `packs/style/` 里的数值目标，写完一章就量，超标就退回重写。

尤其是 **段均 47~49 字**：这是这类书的呼吸。现在框架生成的章节段落明显更长更「文学」，读起来不是一回事。

### 2.2 章标题是台词，不是概括

| | 大宋有种 | 抢救大明朝 |
|---|---|---|
| 台词/喊话式（带！？或含第二人称） | 69% | 42% |
| 含逗号（双句/对偶） | 46% | 31% |
| 直呼对手名字「XX，你……」 | 39 次（1/14 章） | **89 次（1/25 章）** |

复用的标题模板库（抢救大明朝里的出现次数）：

```
「XX，你……！」直呼对手         89   （黄台吉，你要挺住啊！／吴三桂，你什么时候死？）
「什么？……」                   39   （什么？大清没了！／什么？谁被卖掉了？）
「XX要完」                      16   （大清要完？／留给南宋的时间不多了）
「大明好X／大清好X」             15   （大明好岳父／大清好女婿／满洲好兄弟）
「快……」                       11
「XX不哭」                        6   （多尔衮不哭／太子妃，别害怕）
「XX之死」                        5
```

**这是一个可以直接写进 packs 的模板库**，配上「本书已用过的名字」就能生成。

### 2.3 大事件 = 一个事件 × N 个视角（不是 N 个事件）★

这是最重要的一条，也是现有框架错得最狠的一条。

《抢救大明朝》有 21 个「连续同题块」，覆盖 4.2% 的章节。最长的一块：

**第 852–876 章，连续 25 章全叫《什么？大清没了！》**，约 6.3 万字，写的是同一场战役及其余波。逐章视角：

| 章 | 视角 |
|---|---|
| 852 | 史可法（明军主帅）在河间的军议 |
| 853 | 多铎（清军主帅）的战前布署与懊悔 |
| 856 | 明军 32 个火枪连的齐射（群像/战史体） |
| 860 | 詹岱（清军一个巴图鲁）冲锋途中的恐惧 |
| 866 | 索尼进北京，向太后转达屈辱条件 |
| 872 | 布木布泰（孝庄）叩见朱慈烺 |
| 876 | 鳌拜投降，主角发现「满洲第一勇士」是个怂人 |

**25 章几乎全是不同人的眼睛，而且大半是输家的眼睛。**

其他同题块：`敌在天津卫`×7、`一考订终身`×6、`炮打黄台吉`×6、`孔子保佑，刀枪不入`×5、`大清又要完啦！`×5、`如何成为忠烈`×10、`第一帝国之兴亡`×5、`李自成之死`×4、`分田分地扎根`×3。

对照现在的框架：`chapter_outlines.json` 里 **346 章 = 346 个不同事件**。一章一个新事件，于是：
- 事件密度撑不住 → 只能编，编出来的事件互相不咬合 → 剧情碎
- 状态每章都被推一下 → 状态漂移 → 对不上
- 没有任何一章是「从别人眼里再看一遍刚才那件事」→ 读者对事件没有立体感

**改法很直接：细纲生成时允许并鼓励「事件跨章」，一个事件配 3–25 章，每章换一双眼睛。**
框架里已经有 `重场` 字段，缺的是 `事件ID` + `本章视角人`。

### 2.4 六本账 + 一本「债」

《大宋有种》的六本账是 兵/地/名分/钱/技术/制度。《抢救大明朝》把「钱」这一格拆成了主账本，而且是**负债**：

```
大明太子，有债必偿 / 大明贷王 / 大明好债主 / 欠了那么多高利贷，能不拼命？
发债喽，快来买啊！ / 小藩债，大金融 / 大明铁银行 / 朝会怎么变成了招股会？
一亿三千万两就是个小目标 / 皇帝圈钱啦！ / 大负翁路易 / 有借有还，诚信天皇
```

主角的金手指不是武力，是**特许金融分析师**。第 1 章他做的第一件事是拿毛笔画一张 SWOT 表格分析「大明这家公司」；第 3 章他说服王承恩用的是「放弃亏损业务，把精力集中到赚钱的市场」——**资产重组**。

这说明：**六本账的账目名是可换的，但「有一组可数的、只进不退、每动一格必付代价的硬账」这件事是不变的。**

### 2.5 主动制造误读 ★

《大宋有种》的误读大多是**被动**的（主角做事，别人误解）。《抢救大明朝》多了一层：**主角主动生产误读**。

第 2–3 章：王承恩问「听说太祖给您托梦了？」主角一点就透 ——「似乎是梦见老祖宗了」。他不说死，让老实人自己往套里钻。第 3 章末尾王承恩喜极而泣：「太祖高皇帝真的托梦了！」

此后「太祖转世」这个自己造的误读被反复提款：第 162–163 章《太祖高皇帝再世》、第 166 章《朱元璋真的回来了？》、第 183 章《要让大家都知道太祖爷转世了》、第 185 章《太子爷是太祖转世的吗？》。

同理还有「忠义证书」（第 71 章）—— 主角发明一张纸，让人拿着去投降当汉奸，再回来当忠臣。第 1629 章崇祯回顾时点破了这个机制：「骆养性和光时亨……拿着忠臣证书去投降！投降来，投降去，居然投降成了后世敬仰的忠臣了！」

**框架含义**：`misreads.json` 里要区分两类 —— `passive`（被误读）和 `planted`（主角埋的）。后者是可以长期复利的资产，要有「提款记录」。

### 2.6 概念升级链同样存在，而且更长

```
1–130    出北京活命          → 活下来了，但朝廷没钱
130–260  抢钱（勋贵/盐商/东林）→ 有钱了，但没兵没地
260–460  均田分地 + 练新军     → 有兵了，但北方还在清手里
460–560  北伐、灭顺、平三藩    → 打赢了，但天下变大了
560–900  灭清、拿蒙古、开殖民  → 出去了，但列强也在扩张
900–1300 世界贸易/债务/科举殖民→ 赢了，但资本主义自己出问题
1300–1620 世界大战与瓜分      → 统一世界了，但「朕的大明怎么就没了？」
1629–2272 二周目：崇祯重生     → 重来一遍，最后落到立宪
```

每一环仍然是「解决了，但是……」。第 1614–1617 章的标题直接把这条链写在脸上：《不对啊，世界都变了！》《我是败家子》《朕的大明怎么就没了？》《要做世界的主人！》

## 三、这本独有的东西（→ 属于种子或高级玩法）

### 3.1 二周目：书中书 ★

第 **1629 章《我朱由检又回来啦！》** 起，整本书重启：90 岁的崇祯太上皇死了，魂穿回**天启七年八月十二日**的信王朱由检身上 —— 他哥天启当晚要传位给他。此后 **1629–2272 章，约 644 章 160 万字，是一整本独立的书**，主角是父亲崇祯，而朱慈烺在里面是个「三岁监国、五岁出征」的**逆子配角**。

这不是番外，是**同一个种子模板换个壳再跑一遍**：
- 时钟不变（甲申、松锦、黄台吉）
- 壳换了（太子 → 他爹，起点提前 17 年）
- 反直觉动作换了（追父皇 → 自己就是那个不肯跑的皇帝，还御驾亲征、打黑枪、亲手抓老鼠）
- 金手指换了（金融分析 → 五十年旁观圣君儿子攒下的经验）

第 1629 章开头两千字，崇祯用「怎么当圣君」两条心得把上一周目做了完整总结 —— **等于作者当着读者的面把自己的方法论念了一遍**，然后再演示一次。

《大宋有种》末尾那 49 万字赵桓视角番外，是这个手法的种子形态。这本把它做成了主体的 28%。

**框架含义**：一本书写到状态账全部拉满、概念升级到顶（「统一世界」）之后，还能继续的唯一办法就是**换壳重跑**。这可以做成一个显式的生产线动作：`respawn`（换壳重开），输入是同一个 clock + 新的 shell + 新的 counter_move。

### 3.2 标题形态随卷升级

前 1000 章是短句喊话（`大明好岳父`、`快把兵权交出来！`）。
1890 章之后切成**章回体对偶**：

```
朝求升，暮求合，陕西贫汉投崇祯
江南才子带路要饭，后金大汗两路来攻
崇祯帝磨刀向东南，大贵妃性急伐草原
多尔衮倒斗入朝鲜，朱由检要饭去巴蜀
崇祯帝单骑赴会，豪贝勒小心火铳
```

含逗号双句标题占比：抢救大明朝 31%、大宋有种 46%。**标题的形式本身在跟着格局升级** —— 从街头喊话到史书笔法。

## 四、对生产线的补充改动

在 [`DECONSTRUCT_大宋有种.md`](DECONSTRUCT_大宋有种.md) 第四节 10 条的基础上追加：

### 追加 11 ★★★ 细纲允许「一事多章 · 一章一眼」

细纲新增两个字段：

```
event_id ：本章所属事件（多章共享同一个 id）
视角     ：本章由谁的眼睛看（同一 event 内不得重复，且过半应为对手/输家）
```

生成规则：
- 大事件按重要度分配 3–25 章，**同一事件内不许推进新的事件**
- 同一事件内每章换视角，优先顺序：对手主帅 → 对手小兵 → 中立旁观者 → 我方将领 → 主角
- 同题块内标题可以完全相同（原作 25 章一个标题），或加 `（一）（二）`

这一条同时治「剧情不连续」（事件不用编了）和「状态没对上」（一个事件只动一次账）。

### 追加 12 ★★ 误读分两类，埋的那种要记提款

`misreads.json` 每条加 `kind: passive | planted`。`planted` 的（太祖托梦、忠义证书）要记录每次被提款的章号，**并强制在后 50 章内至少提款一次**，否则算浪费资产。

### 追加 13 ★★ 标题模板库 + 已用名单

`packs/style/` 下建标题模板表（§2.2 那七个模板 + 示例），细纲生成时随机取模板、填入本章的对手名。硬规则：**连续 10 章不得用同一个模板**。

### 追加 14 ★ 文体数值当验收标准

把 §2.1 的表做成 `scripts/stagecheck.py` 的硬门槛：

```
对白占比        22%–28%
每千字问号      4.5–6.5
每千字叹号      7.5–10.5
段落平均字数    40–60      ← 现在生成的明显偏长
段落数/章       按章长换算，约 每 55 字一段
```

不达标退回重写。这不是审美偏好，是两本独立统计咬合出来的。

### 追加 15 ★ 加一个 `respawn` 动作

当六本账全部拉满、概念升级链走完，不要硬续。提供换壳重开：同一个 clock，换 shell、换 counter_move、换金手指，上一周目的主角降为配角。原作用这招吃下了 160 万字。

## 五、种子模板（两本合并校准后）

```yaml
clock:            # 与主角无关、有明确日期、读者已知的倒计时
  大宋有种: 宣和七年冬金兵渡黄河 → 一年内二帝北狩
  抢救大明: 崇祯十七年三月李自成进北京 → 几天之内
shell:            # 主角占的壳，在真实历史里下场很惨且读者知道
  大宋有种: 郓王赵楷，输掉储位，被掳五国城
  抢救大明: 太子朱慈烺，16 岁，甲申后下落不明
counter_move:     # 把这个身份的常规反应反过来的那一个动作
  大宋有种: 不夺位，逼父皇别退位，自己去前线   →「父皇别跑，儿臣有种！」
  抢救大明: 不逃命，带兵追住要亲征的父皇       →「父皇别跑，儿臣孝顺！」
cheat:            # 金手指必须是「一种分析世界的方法」，不是一种力量
  大宋有种: 四大兵法 + 后世历史知识
  抢救大明: 特许金融分析师（SWOT、资产重组、忽悠）
prepaid_emotion:  # 读者不用铺垫就有感情的名字
  大宋有种: 靖康之耻 / 岳飞 / 秦桧 / 赵构
  抢救大明: 崇祯上吊 / 吴三桂 / 洪承畴 / 史可法 / 李自成 / 多尔衮
accounts:         # 六本硬账，名字可换，「只进不退且每动必付代价」不可换
  大宋有种: 兵 地 名分 钱 技术 制度
  抢救大明: 兵 地 名分 债 技术 制度        ← 钱换成了债
volume_chain:     # 但是链，volume[i].exposes == volume[i+1].solves
planted_misreads: # 主角准备主动生产的误读（可选但强烈建议）
  抢救大明: 太祖托梦 / 忠义证书
```

**注意 `cheat` 那一行**：两本的金手指都不是战力，是**一套看世界的方法**（兵法 / 金融分析）。方法能持续产出新解法，战力只能产出一次爽点。现在 `project.json` 里写的「一把沙漠之鹰、一百二十发子弹」是后者 —— 它有上限，打完就没了，撑不起三百章。
