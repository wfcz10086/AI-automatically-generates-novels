# 老辣调生产线：提示词全文

反推自大罗罗两本共 796 万字（《大宋有种》555 章 / 《抢救大明朝》2278 章）。
配套：[`packs/style/laolatiao.json`](../packs/style/laolatiao.json)、[拆书·大宋有种](DECONSTRUCT_大宋有种.md)、[拆书·抢救大明朝](DECONSTRUCT_抢救大明朝.md)。

现有框架的死板不在提示词写得不够长，在**流程本身**：346 章细纲一次排完，然后照单填字。
这份文档换掉流程：**不排细纲，推演回合**。

## 零、主调

> 用一个现代内行人的眼睛，看一个正在塌方的旧体制。台上所有人都在算自己的那本账，没有好人坏人，只有算得清和算不清的。叙述者永远比场上的人多知道一层，而且忍不住用一句大白话，把刚刚说完的那句正经话戳破。

三条腿（缺一条就不是这个调子）：

1. **内行人的眼睛** —— 金手指必须是一套**看世界的方法**（兵法／金融分析／律法／医术／工程），不是一种力量。方法能持续产出新解法；力量只能产出一次爽点。
   > 《抢救大明朝》第 1 章：主角做的第一件事是拿毛笔画一张 SWOT 表格分析「大明这家公司」。第 3 章他说服王承恩用的是「放弃亏损业务，把精力集中到赚钱的市场」。
   > 现有项目里写的「一把沙漠之鹰、一百二十发子弹」是后者——它有上限，打完就没了，撑不起三百章。

2. **所有人算自己的账** —— 不存在为阻挡而阻挡的反派。每个配角的动机都能换算成他自己的得失，并且写给读者看。角色的功能随局势翻转。

3. **叙述者高一层** —— 每写完一段庄严的、悲壮的、正经的内容，接一句大白话把它戳破。
   > 两本独立统计：反讽旁白引导词密度 **22.4 / 22.1 每万字**，几乎完全一致。这是作者的嗓子，不是某本书的设定。

## 一、种子发散提示词

替换现在 `project.json` 的 `premise / background / relationships`。那三个字段发散出来的必然是「主角很强 → 越来越强」。

````
你要为一本长篇通俗历史小说定种子。种子不是人设，是三个约束撞在一起产生的火花。

用户的想法：{{IDEA}}

请输出下面八项，每项都要具体到能查证、能落笔：

【1】clock —— 时钟
  一件与主角无关、有明确日期、目标读者已经知道结局的灾难或倒计时。
  它必须自己走，主角不动它也会到。全书所有紧迫感都从这里来。
  例：宣和七年冬金兵渡黄河，一年内二帝北狩／崇祯十七年三月李自成进北京，只剩几天。
  写法：{事件} + {起始日期} + {不干预的话多久落地} + {落地后主角的下场}

【2】shell —— 壳
  主角占的这个身份，在真实历史里下场很惨，而且读者知道有多惨。
  不许是无名小卒，也不许是本来就赢的人。
  例：郓王赵楷（输掉储位、被掳五国城）／太子朱慈烺（16 岁，甲申后下落不明）

【3】counter_move —— 反直觉动作 ★最重要
  把这个身份的常规反应**反过来**的那一个具体动作。一句话，动词开头。
  检验标准：把这句话讲给熟悉这段历史的人听，他的第一反应必须是「他疯了？」
  例：不夺位，反而带兵逼父皇继续当皇帝，自己跑去前线
      不逃命，反而拎着剑追住要御驾亲征的父皇
  同时给出这个动作的**第一句台词**，全书的书名应该就是它。
  例：「父皇别跑，儿臣有种！」「父皇别跑，儿臣孝顺！」

【4】cheat —— 金手指
  必须是一套**分析世界的方法**，写明它是哪个现代行当的看家本事。
  同时写明它的**盲区**：它解决不了哪一类问题（后面所有的挫败都从盲区来）。
  例：特许金融分析师（SWOT／资产重组／忽悠）。盲区：算得清账，打不过人。
  禁止：一把枪、一个系统、一本秘籍、一次性的道具。

【5】prepaid_emotion —— 预装情绪
  6~10 个读者不用铺垫就有感情的真实人名／事件。列出来，标明读者对每个人预存的是什么情绪。
  例：岳飞（惋惜）、秦桧（恨）、赵构（鄙夷）、靖康之耻（屈辱）

【6】accounts —— 六本硬账
  给这本书六个可数的状态账，名字要贴这本书。
  规则：只进不退，每动一格必须付出一笔可查的损失。
  例：兵／地／名分／钱／技术／制度　　或　　兵／地／名分／债／技术／制度

【7】volume_chain —— 但是链，至少 6 环
  格式严格为：{solves: 这一卷解决什么, exposes: 解决之后新长出什么问题}
  硬约束：volume[i].exposes 必须等于 volume[i+1].solves。
  每一环的解法必须让上一环的解法失效——不许写成能力叠加。
  例：活命 → 没名分 → 没钱没地 → 得罪整个士大夫 → 三分天下打不动 →
      技术碾压统一 → 天下变大了 → 没有意识形态撑不住 → 儿子们要争

【8】planted_misreads —— 主角准备主动生产的误读，2~3 条
  主角自己造、让别人愿意相信、可以反复提款的假解释。
  例：太祖托梦（提款：太祖转世、朱元璋回来了、太子是太祖转世吗）
      忠义证书（提款：拿着它去投降当汉奸，再回来当忠臣）

不许输出「三条感情线」「主角性格缺陷」「爽点密度表」这类东西。种子只管发散，不管排布。
````

## 二、卷纲提示词（但是链）

````
根据种子的 volume_chain，为第 {{i}} 卷写卷纲。

必须输出以下六项，不许写成事件流水账：

一、期初状态向量：六本账在本卷开始时的实值（从 world_state.json 读，原样抄，不许改）
二、期末状态向量：本卷结束时六本账应该是多少
三、本卷要作废的东西：上一卷的最优解，在本卷为什么不管用了
四、时钟刻度：本卷这段时间里，外部世界【与主角无关地】自己会发生什么（至少 3 条）
五、持续误读源：本卷里谁会一直误解主角、误解成什么、他为什么非这么想不可
六、代价账：本卷要付出的结构性损失——谁受损、损失多少、能不能恢复

反面例子（不要这样写）：
  「本卷主线：主角进入东京权力体系，与蔡京集团博弈，同时发展北方商路。」
  —— 这是流水账，没有账目、没有作废、没有代价。

正面例子（《大宋有种》第三卷的实际内容）：
  三、要作废的：靠打胜仗换资源。府兵制建立后，兵不再从战场上来，从土地上来。
  六、代价账：陕西／河东／京西／河北四路再无民田，朝廷税基只剩四川、荆湖；
      得罪十万户地主乡绅，必须先派十六员大将出洛阳弹压才敢分田。不可恢复。
````

## 三、剧情推展：回合推演 ★核心

**这一节替换掉现在的「批量生成细纲」。**

现在的做法是：346 章细纲在正文只写了 6 章时两小时内排完 → 每章一个新事件 → 事件编不出来就注水 → 状态每章被推一下 → 漂移。

原作的做法是：**一个事件配 3~25 章，每章换一双眼睛**。《抢救大明朝》第 852–876 章连续 25 章全叫《什么？大清没了！》，写的是同一场战役，视角依次是史可法 → 多铎 → 明军火枪连 → 清军巴图鲁詹岱 → 索尼 → 孝庄 → 鳌拜，**大半是输家的眼睛**。

所以推展的单位不是「章」，是「回合」。一个回合产出一个事件包。

### 3.1 一个回合的四步

```
第一步 世界自转 ── 各势力按自己的账各走一步（完全不管主角在干什么）
第二步 碰    撞 ── 自转结果 × 主角当前处境 → 逼出一个他必须回应的局面
第三步 反直觉动作 ── 从 counter_move 的性子出发，选一个所有人都想不到的做法
第四步 误读扩散 ── N 个人各自误读这个动作 → N 条后果
                   其中最大的一条，就是下一个回合第二步的输入
```

事件不是排出来的，是**算出来的**。这就是「发生」。

### 3.2 世界自转提示词

````
这是一次【世界回合】。主角不在场，不许提到主角在做什么。

各势力当前状态（factions.json）：
{{FACTIONS}}

时钟：{{CLOCK}}　　已经过去：{{ELAPSED}}

请让下面每一个势力，按【它自己的目标和它自己的内部矛盾】，各自往前走一步。
对每个势力输出：
  它这段时间最想要什么
  它内部谁和谁在争，争什么
  它实际做了什么（一个具体动作，不是「继续发展」）
  这个动作让它自己的账变成了多少
  这个动作在它自己看来是聪明的，但埋下了什么它没看见的隐患

硬要求：
- 至少有一个势力做出【对它自己不利】的动作，因为内部斗争压倒了外部理性。
  （参考：完颜宗构党争、大清父慈子孝、赵构在金陵一口气取四百武进士）
- 至少有一个势力因为误判主角而做出动作。
- 不许所有势力都在针对主角。它们大部分时间在互相咬。
````

### 3.3 碰撞 + 反直觉动作提示词

````
世界自转的结果：{{WORLD_TURN}}
主角当前处境：{{HERO_STATE}}（六本账 + 手上的人 + 欠的债 + 还没兑现的承诺）
主角的性子（counter_move）：{{COUNTER_MOVE}}
主角的金手指与它的盲区：{{CHEAT}}

第一问：上面的自转结果里，哪一条构成【主角不回应就会掉一格账】的局面？
        写清楚是哪一格、掉多少、多久之内。

第二问：常人在这个局面下会怎么做？列出 3 个所有人都预期他会做的选项，
        并写明每个选项的代价。

第三问：这个主角会怎么做？必须满足全部四条：
        （a）三个常规选项之外
        （b）用他的金手指方法，不是用力量
        （c）在他自己的逻辑里完全说得通，能一句话讲清
        （d）第一次听说的人反应是「他疯了？」

第四问：这个动作要付出什么代价？记进代价账。

第五问：给这个动作配一句台词。口语、反常识、最好带点自嘲或不要脸。
        参考：「孤家带兵来尽孝」「父皇别跑，儿臣孝顺」「大金不做选择题」
              「你过河、我拆桥」「队友就是拿来出卖的！」
````

### 3.4 误读扩散提示词 ★

这是全套流程里投入产出比最高的一步。**一个动作 × N 个误读者 = N 条新支线**，不用另外设计情节。

````
主角刚做的动作：{{ACTION}}
他的真实意图：{{TRUE_REASON}}

下面这些人看见（或听说）了这个动作。他们**都不知道**他的真实意图。
{{OBSERVERS}}

对每一个人，输出五项：
  who       他是谁
  because   他凭什么这么想（他的处境、他的知识、他吃过的亏、他正在怕的事）
  concludes 他得出的【错误】结论
  acts      他因此做了什么（必须是一个具体动作）
  spawns    这个动作制造了什么新局面

硬要求：
- 每个人的误读方向必须不同，而且都要比主角的本意【更大、更凶险】。
- 至少一个人的误读对主角有利，至少一个不利。
- 至少一个误读会在 30 章以后才结账（写进 alive_until）。

参考（《大宋有种》第 20–21 章的真实误读）：
  动作：赵楷在陈桥驿扎营过夜　　真实意图：他太困了，想睡一觉
  ① 崇政殿宰执：陈桥驿是太祖黄袍加身处 → 他要称帝 → 闭嘴不敢弹劾
     → 朝廷失去了对赵楷的全部约束力
  ② 自己的部下：同上 → 该劝进了 → 商量去找一件黄袍
     → 第 21 章主角被妹妹一嗓子吼醒，被迫当场表态
````

### 3.5 事件切章提示词

````
事件：{{EVENT}}
它在六本账上造成的变化：{{DELTA}}
围绕它的误读：{{MISREADS}}

第一问：这个事件值几章？
  参考原作的实际配比 —— 决定国运的大战役 15~25 章；一场攻防或一次朝堂摊牌
  5~8 章；一次谈判、一次抄家、一次科举 3~5 章；日常推进 1~2 章。
  值几章就写几章，不许为了凑数把一个事件掰成几个假事件。

第二问：这几章分别用谁的眼睛看？
  硬规则：同一事件内不得重复视角；过半必须是【对手或输家】的眼睛；
  主角本人的视角不得超过三分之一；至少有一章用小人物的眼睛
  （一个巴图鲁、一个画师、一个酒楼里的商人、一个验尸的仵作）。

第三问：这几章的标题。
  同一事件可以连用完全相同的标题（原作最长连用 25 章），也可以加（一）（二）。
  标题必须是台词、反问或喊话。禁止意象概括。
  从模板库里取，连续 10 章不得用同一个模板：
  {{TITLE_TEMPLATES}}

第四问：这个事件在哪一章动账？只能动一次。写明 from → to。
````

## 四、章细纲提示词

字段比现在多四项：`视角 / 误读 / 账目 / 代价`。这四项正好是「发生」和「状态」。

````
写第 {{N}} 章的细纲。

本章所属事件：{{EVENT_ID}}　{{EVENT}}
本章在事件里的位置：第 {{K}} 章 / 共 {{TOTAL}} 章
本章视角人：{{POV}}（本章从他的眼睛看，他不知道主角在想什么）
世界当前状态：{{WORLD_STATE}}
活跃误读：{{MISREADS}}
最近三章的正文原文（承接文风、称谓、场景细节）：{{RECENT_TEXT}}

输出以下字段，缺一不可：

标题　　　一句台词／反问／喊话，从模板库取
视角　　　{{POV}}；他现在的处境、他今天最怕什么、他今天想要什么
承接　　　上一章章末那条新消息，在本章第几段落地
动作　　　主角做的那一个动作（动词开头，一句话）
误读　　　本章新产生或被消费的误读：谁 + 凭什么 + 读成什么 + 因此干了什么
后果　　　这个误读生出的新麻烦（下一章的输入）
账目　　　本章动了哪一格：{账名} from {旧值} → to {新值}；不动账就写「本章不动账」
代价　　　谁受损、损多少、可否恢复；没有代价就写「本章无代价」
解说　　　本章要讲透的那一条制度／数字／器物（一句话）
重场　　　哪一段是本章的重心
章末　　　一条新消息／一个新名字／一句让读者替某人着急的话
          禁止：感想、总结、决心、「他知道，这只是开始」

反面例子（现有项目里真实的第 2 章细纲，别这样写）：
  「爽点：雷横拿钱办事、睁只眼闭只眼，本地权力结构在枪威与金钱下迅速向西门庆倾斜。」
  —— 这是对写法的点评，不是事件。爽点要写「谁在什么场合被怎样了／主角拿到了什么」。
````

## 五、正文提示词

关键改动：**把真片段贴进去当调子样例**，而不是用形容词描述风格。
按本章要用到的功能，从 `packs/style/laolatiao.json` 的片段种子库取 2~3 条。

````
本章细纲：{{OUTLINE}}
最近两章正文原文：{{RECENT_FULL}}
世界状态与硬约束：{{CONSTRAINTS}}

── 调子 ──
{{TONE}}   ← packs/style/laolatiao.json 的「主调」原文

下面是同类作品里几段真东西。不要抄内容，听它的嗓子：

【外部视角开场】
{{SEED_OPENING}}

【反讽旁白·把正经话戳破】
{{SEED_IRONY}}

【误读推断·别人算错】
{{SEED_MISREAD}}

【算自己的账】
{{SEED_INTEREST}}

【制度解说·把规矩讲透】
{{SEED_EXPLAIN}}

【断章钩子】
{{SEED_HOOK}}

── 硬指标（写完会被机器量，不达标退回重写）──
对白占正文比 20%~28%
每千字问号 4.5~6.5　　每千字叹号 7.5~10.5
段落平均字数 40~62，单段不得超过 200 字
独立成段的反问句 3~6 个（必须是角色的疑问，不是叙述者的）
反讽旁白 2~4 处
本章至少 1 处别人对主角的错误推断，并写明他凭什么这么想
本章至少 1 段把一条制度／数字／器物讲透，讲完立刻接一句大白话戳破

── 硬规矩 ──
1. 开场用 {{POV}} 的眼睛，不是主角的。前 300 字里主角可以不出现。
2. 配角开口前，先让读者知道这句话对他自己有什么好处。
3. 不许替主角辩护。叙述者可以笑他，不许夸他。
4. 章末不许是感想、总结、决心。
5. 本章的账只能按细纲写的动那一格，其余五格原样不动。
````

## 六、验收

写完立刻量，机器判，不达标退回。这些数字不是审美，是两本独立统计咬合出来的。

```python
# scripts/stagecheck.py 追加
GATE = {
  "dialogue_ratio":      (0.20, 0.28),
  "q_per_1k":            (4.5, 6.5),
  "excl_per_1k":         (7.5, 10.5),
  "para_avg_chars":      (40, 62),
  "para_max_chars":      200,
  "standalone_questions":(3, 6),
  "irony_markers":       (2, 5),
  "misread_present":     True,       # 误读推断词至少 1 处
  "explain_present":     True,       # 解说体至少 1 处
  "non_hero_opening":    True,       # 前 300 字不以主角为视角
  "ends_complete":       True,       # 末字符是句末标点、引号闭合
  "length_ok":           True,       # 达到目标字数的 85%
}
```

结构层的校验（每个回合跑一次）：

```
□ 本回合每一章都挂在同一个 event_id 下，没有凭空多出来的事件
□ 同一事件内视角不重复，且过半是对手／输家
□ 本回合只动了细纲声明的那几格账，world_state 与正文一致
□ 本回合至少产生 1 条新误读，或消费 1 条旧误读
□ 埋了 30 章以上还没提款的误读，本回合必须结掉一条
□ planted 类误读（主角自己造的），50 章内至少提款一次
□ 章标题：连续 10 章没有重复模板，没有意象概括
□ 骨架回写：正文与细纲／线索／分卷有冲突时，以正文为准修订骨架
```

## 八、实测：提示词到底怎么写才生效

用 `scripts/prompt_bench.py`（12 步全链路）和 `scripts/draft_ab.py`（正文 A/B）实跑出来的，
不是推测。模型 glm-5.3-flash，每组 3 轮，同一份细纲输入，只改提示词的写法。

### 8.1 第一条：数值指标不可执行，必须翻译成结构指令

**A 组**（现在的写法，给数值目标）：

```
对白占正文比 20%~28%
每千字问号 4.5~6.5；每千字叹号 7.5~10.5
反讽旁白 2~4 处
本章至少 1 处别人对主角的错误推断
```

**B 组**（把每个数值翻译成结构指令 + 起手句式）：

```
▍反讽旁白
　每当你写完一段正经的、庄严的、悲壮的、或者讲道理的内容，
　下一段另起一行，用下面任一个起手，把刚才那段话戳破：
　　「还别说，……」「说穿了，……」「可问题是，……」「这哪儿是……分明是……」
　本章这样戳破三到四次。戳破的时候要用大白话，不要讲道理。

▍别人算错
　本章至少两次，让某个人推断错。写法固定成三步，缺一不可：
　　一、他看见了什么（具体的：一个动作、一句话、一件东西）
　　二、他凭什么这么想——他的处境、他吃过的亏、他此刻正在怕的事
　　三、他因此做了什么
　他必须猜错，而且错得比真相更大更凶险。
```

结果：

| 指标 | A 数值版 | B 结构版 | 原作基准 |
|---|---|---|---|
| 字数 | 1975 | **2728** | 2500 |
| 对白占比 | 0.23 | 0.20 | 0.24 |
| 每千字问号 | 6.60 | **5.19** | 5.30 |
| 段均字数 | 50.2 | 43.2 | 53.0 |
| 独立反问句 | 0.7 | **2.3** | 1.7 |
| **反讽旁白** | 0.3 | **5.3** | 2.0 |
| **误读推断** | 0.0 | **2.7** | 0.6 |
| 解说体 | 0.7 | **3.3** | 1.6 |

给了结构指令的项，全部从「远低于原作」拉到「达到或超过原作」。
误读从 **0 → 2.7**，反讽从 **0.3 → 5.3**。

而且不是凑数字 —— B 组的正文里，误读的三步是这样落地的：

> **看见什么**：「他是看见了那间库房的。散朝之前，武选司的人搬走了一柜空白诏纸。」
> **凭什么**：「因为他这十几年吃过的每一回亏，都是文武衙门从内廷手里抢权抢走的。他怕的就是这个。」
> **因此做了什么**：「于是当夜，赵忠把王德全叫到自己值房，关了门。」

反讽也没油：「还别说，皇帝亲手捧了三十年的东西，扔炭盆的手法相当熟练，一点没磕着炭盆边。」

### 8.2 第二条：没写进去的项会被挤掉 ★

B 组把**叹号密度从 8.20 打到了 0.14**（原作 8.90）—— 因为我给了对白、反讽、问句、误读、
解说各一条结构指令，唯独没给「情绪外放」写指令，它就被挤没了。

补上一条：

```
▍情绪要喊出来
　人急了、怕了、气了、得意了的时候，让他把话喊出来，用感叹号收尾。心里喊的也算。
　例：「完了！司礼监完了！」「这可是泼天的富贵啊！」「他N的，这也太狠了！」
　本章至少六处这样的喊话。人物不许一直端着——这个调子里，端着的人是要吃亏的。
```

叹号密度立刻回到 **8.0**（原作 8.90），而且其他项没掉。

> **结论：提示词里写什么，模型就做什么；没写的会被挤掉。**
> 每一个你想要的东西，都必须有它自己的一条结构指令。列清单不是啰嗦，是必须。

### 8.3 第三条：只给下界会超调，必须给上界

「本章至少这样戳破**四次**」→ 实际做了 **5.3 次**，而原作只有 **2.0 次**。
改成「这样戳破**三到四次**，不要更多——多了就成了念咒，读着油」才收得住。

同理：「至少 1 处误读」会变成 3 处，「至少 3 个独立问句」会变成 5 个。
**凡是给下界的指标一律超调，凡是没提的指标一律归零。**

### 8.4 结构指令的写法模板

```
▍<要什么>
　<在什么时机做>：每当……的时候
　<怎么做>：另起一段 / 三步写法 / 用这几个起手句
　<起手句式或例子>：三到五个，具体到可以照着填
　<上下界>：三到四次，不要更多——多了会……
　<反例>：不许写成「两人商议了一番」这种概括
```

五件都得有。少了「起手句式」模型不知道长什么样；少了「上界」它会超调；
少了「反例」它会用最省事的方式糊弄过去。

### 8.5 模型实测

| 模型 | 每步耗时 | 表现 |
|---|---|---|
| `glm-5.3-flash` | 30~90s | 全链路一轮约 12 分钟。反直觉动作与正文都可用；需要 `reasoning_effort: low`，否则额度全烧在思考里、可见输出为 0 |
| `deepseek-v4-flash` | 种子 288s，其余 30~180s | **慢，但结构质量明显更高**。种子那一步值得用它 |
| `qwen3.8-flash`（项目当前默认） | **单次调用 >280s 超时** | 在 gw4 聚合网关上不可用 |

两个模型都通过了「他疯了？」检验：

> **GLM**：烧掉传国玉玺，宣布一切旧凭据作废。
> 「别人都默认合法性来自王命这个物件；他看穿了：皇帝本人就是王命的实体，印章只是复印件。
> 复印件被伪造了，正常人的反应是补复印件——他的反应是把复印机砸了。」
> 真实意图：「他三天没睡好了……他烦透了当那枚会喘气的印。」

> **DeepSeek**：打开洪武铁匣、当众剃度上殿。「你们不是要清君侧吗？君先把自己变成一个和尚，
> 看你清谁。」金手指是「庙堂剧场术」（政治人类学），**盲区直接咬住时钟**：
> 「只对相信符号的人有效……白沟河的风一落地，庙堂剧场术瞬间变废纸。」

DeepSeek 的六本账没有沿用我给的默认，自己长出了 **疯诏 / 血戒 / 遗诏**，每本自带代价机制。

**建议：按步选模型。** 种子、反直觉动作、误读扩散用贵的；切章、细纲、正文用快的。

### 8.6 验收闸门的教训

第一版闸门把**全书平均**当成了**每章硬指标**，拿原作去过 —— **60 章 0 通过**。

单章方差极大：对白占比 2 分位 0.04、98 分位 0.54（有的章全是武戏，有的章全是朝堂对辩）。

改成两级：

```
单章闸（只拦硬伤）      字数 / 段均 35~80 / 单段≤280 / 对白>0.02 / 结尾完整
                        → 原作通过率 86%~95%

窗口闸（每 10 章滚动）  对白 0.16~0.34 / 问 3.4~7.7 / 叹 6.6~11.3 / 段均 47~62
                        独立反问句≥7 / 反讽≥12 / 误读≥2 / 解说≥8
                        → 原作通过率 65%
```

窗口闸不该硬退回重写（8 项同卡 5/95 分位，理论上限就是 43%），
应该当**软信号回喂下一章的提示词**：「上个窗口问号密度偏低，这几章多让人物发问。」

另外：**误读无法用词表可靠检测。** B 组正文明明有完整的误读三步，但用词是
「老宦是这么算的：皇帝不疯……定向清算！」，一个误读词都没命中。
误读要从**细纲**层结构化校验，不要从正文层用正则数。
