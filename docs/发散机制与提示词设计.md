# 种子怎么长成五百万字：发散机制与提示词设计

这份文档回答一个问题：**一个五行的种子，凭什么能长出 2278 章？**

答案不是「规划得更细」。原作从来没有规划过 2278 章。
是因为它跑的是一个**递归**：这一轮的输出，就是下一轮的输入。

---

## 一、先看一段真实的发散

《大宋有种》的种子只有一句：**「不夺位，反而逼父皇继续当皇帝」**。
下面是它头三轮怎么滚出前 30 章的 —— 注意每一轮的**输入都是上一轮的输出**。

### 第 1 轮

| | |
|---|---|
| **输入** | 时钟：金兵过黄河，几日内父皇要退位跑路；壳：赵楷，输掉储位 |
| **动作** | 带 300 人闯东华门 |
| **真实意图** | 不让爹跑。爹一跑，他就是绿帽子王，全家去五国城 |
| **误读①** | 何灌与两府宰执 —— 凭「大宋一百六十年没有亲王带兵闯宫」→ 读成**玄武门之变** → 不敢拦，让路 |
| **误读②** | 部下黄无忌 —— 凭主角一句「事成当与你共富贵」→ 读成**要夺嫡** → 纳头便拜 |
| **账** | 兵 0→300；名分 「输掉储位的闲王」→「敢带兵逼宫的疯王」 |
| **代价** | 满朝敌视。所有原本支持他夺嫡的人反水 |

### 第 2 轮（输入 = 第 1 轮的代价）

| | |
|---|---|
| **输入** | 他留在开封就是所有人的眼中钉；同时金兵已过相州 |
| **动作** | 主动宣布「孤要带兵去河北，向金人求饶」 |
| **真实意图** | 找个所有人都批准的借口，带着兵和老婆离开开封 |
| **误读①** | 朝臣 —— 读成**他要去卖国** → 巴不得他快走，还从内藏拨 30 万贯「求饶费」 |
| **误读②** | 金人 —— 读成**宋朝出了个疯子** → 开始警惕 |
| **账** | 钱 0→30 万贯；地 开封→出城；名分 +「疯王」 |
| **代价** | 「卖国」这口锅背上了，后面几十章反复回响 |

### 第 3 轮（输入 = 上一轮拿到的兵和钱 + 一个纯粹的意外）

| | |
|---|---|
| **输入** | 他太困了。这几天没睡过 |
| **动作** | 在陈桥驿扎营，睡一觉 |
| **真实意图** | 睡觉。就是睡觉 |
| **误读①** | 崇政殿宰执 —— 凭「陈桥驿是太祖黄袍加身处」→ 读成**他要称帝** → 集体闭嘴，不敢再弹劾 → **朝廷失去了对他的全部约束力** |
| **误读②** | 自己的部下 —— 同上 → 读成**该劝进了** → 真的去商量找一件黄袍 → 主角被妹妹一嗓子吼醒，被迫当场表态 |
| **账** | 制度 无→陈桥驿改编（军议制、主帅着武人服、五条军议规矩） |
| **代价** | 从此他必须一直「像个要当皇帝的人」，退不回去了 |

### 看出规律没有

三个动作分别是：**闯个门、说句话、睡一觉**。没有一个是「精彩情节」。

但三轮下来，六本账翻了三倍，还长出了「卖国」「疯王」「黄袍加身」三条能烧几十章的长线。

**发散不是想出更多情节，是让后果自己长。**
作者要做的只是：给一个小动作，然后**老老实实结算每个人会怎么误会它**。

## 二、发散算子：只有五个

把两本书 796 万字的新材料来源归类，只有五个算子。种子要做的，是给这五个算子备好燃料。

### 算子 1：误读 —— 一变多（主力，约七成新材料）

```
一个动作 × N 个观察者 = N 条新支线
```
观察者越多、彼此处境差得越远，产出越多。这是**唯一一个能凭空造出情节的算子**，而且不花设计成本 —— 你只需要老实推演「他凭什么这么想」。

### 算子 2：代价 —— 一变二

```
升级 → 一笔可查的损失 → 受损的人 → 新对手
```
> 分田养 36 万府兵 → 四路再无民田、税基只剩四川荆湖 → 十万户地主受损 → 必须先派十六员大将出洛阳弹压 → 弹压又生出地方新矛盾

没有代价的升级是死路：它不产生任何新东西。**这就是为什么「越来越强」写不长。**

### 算子 3：自转 —— 横向加宽

```
各势力在主角不在场时也在走 → 主角回头一看，世界变了
```
> 完颜宗构党争、大清父慈子孝、赵构在金陵一口气取四百武进士、耶律大石西迁称帝

### 算子 4：作废 —— 纵向加深

```
解决了 → 但是暴露了新问题 → 上一档的最优解失效
```
防重复的唯一手段。没有它，写到一百章就开始原地打转。

### 算子 5：换壳 —— 重启

```
六本账全满、议题升到顶 → 同一个时钟，换个壳，重跑
```
> 《抢救大明朝》第 1629 章，90 岁的崇祯太上皇死后魂穿回天启七年的信王身上，重开 644 章 160 万字，上一周目的主角朱慈烺在里面是个「三岁监国」的逆子配角。

## 三、提示词设计的总原则：让模型**结算**，不要让它**规划**

这是整件事的关键，也是现有框架最根本的毛病。

| | 规划式提示词（现在） | 结算式提示词（应该） |
|---|---|---|
| 问法 | 「请规划接下来 40 章的剧情」 | 「根据这些人的处境和这些账，接下来会发生什么？」 |
| 模型在干什么 | **创作决策** | **推理** |
| 结果 | 收敛到训练数据的众数 —— 也就是最平庸的那条路 | 会产生连提问者都没预料到的结果 |
| 症状 | 「主角进入东京权力体系，与蔡京集团博弈」这种正确的废话 | 「宰执们因为不敢弹劾，反而把约束力自己交出去了」 |

一旦你问「请设计一个精彩的冲突」，模型就会去检索"精彩冲突"的模板；
你问「李邦彦这个人，现在最怕什么？他看见主角带兵扎在陈桥驿，会怎么想？」，模型就得**算**。

算出来的东西才有意外。

### 由此派生的六条设计手法

**手法 1：给约束和私利，不给目标**
不要写「本章要有一个爽点」。要写「李邦彦现在的处境是 X，他最怕 Y，他看见了 Z」。
情节从约束里掉出来，不是被指定出来的。

**手法 2：强制「先想法、后事件」的输出顺序**
提示词必须要求模型**先**逐个写出每个人怎么想，**再**写发生了什么。
顺序反过来（先定事件、再补动机）就退化成了规划，动机会变成事后找补。

**手法 3：不让它知道正确答案**
生成误读时，明确写「他**不知道**主角的真实意图」，并要求「他的结论必须是**错的**，而且比真相**更大更凶险**」。
模型天然想让角色猜对 —— 必须用提示词把这个倾向压住。

**手法 4：让它自己找矛盾点**
不要说「本回合的冲突是 X」。要问：
> 「上面这些自转结果里，哪一条构成主角不回应就会掉一格账的局面？是哪一格、掉多少、多久之内？」
让它自己指认，比你指定给它更准。

**手法 5：「他疯了？」检验**
反直觉动作必须过这一关：
> 「把这句话讲给熟悉这段历史的人听，他的第一反应必须是『他疯了？』」
过不了就重来。这一条挡住了 90% 的平庸方案。

**手法 6：禁止总结**
章末不许写感想、决心、「他知道这只是开始」。
模型总结的那一刻，就是它停止推理、开始归纳的那一刻 —— 而归纳出来的永远是套话。

## 四、发散的提示词：一个回合的完整链条

一轮五道题，前一题的答案是后一题的输入。**每道题单独调用一次模型**，不要合成一次问完 —— 合起来问，模型会先想好结局再倒推，那又变成规划了。

### 第 1 问 · 自转（主角不在场）

````
主角不在场。下面每个势力，按【它自己的目标和它自己的内部矛盾】各走一步。
{{FACTIONS}}　时钟：{{CLOCK}}　已过去：{{ELAPSED}}

每个势力输出：它这段时间最想要什么／它内部谁和谁在争／它实际做了什么（一个具体动作，
不许写「继续发展」）／它自己的账变成了多少／它自认为聪明但没看见的隐患。

硬要求：
- 至少一个势力做出【对自己不利】的动作，因为内部斗争压倒了外部理性
- 至少一个势力因为误判主角而行动
- 不许所有势力都在针对主角，它们大部分时间在互相咬
````

### 第 2 问 · 找矛盾（让它自己指认）

````
自转结果：{{WORLD_TURN}}
主角当前六本账：{{ACCOUNTS}}　手上的人：{{ROSTER}}　欠的债：{{DEBTS}}

上面哪一条，构成【主角不回应就会掉一格账】的局面？
写清楚：是哪一格、掉多少、多久之内、掉了之后他会怎么样。
如果有多条，选最急的那一条，并说明为什么它比其他几条更急。
````

### 第 3 问 · 常规解（先把平庸选项摆出来，好避开）

````
局面：{{SITUATION}}

一个正常人在这个位置上会怎么做？列出 3 个所有人都预期他会做的选项。
每个选项写明：谁会支持、代价是什么、为什么它是"正常"的。

这一问的目的是把平庸方案穷举出来 —— 接下来主角**不能**用这三条里的任何一条。
````

### 第 4 问 · 反直觉动作

````
三个常规选项：{{OBVIOUS}}
主角的性子：{{COUNTER_MOVE}}
主角的金手指（一套看世界的方法）与它的盲区：{{CHEAT}}

这个主角会怎么做？必须同时满足：
（a）不在上面三个选项里
（b）用的是他的【方法】，不是力量
（c）在他自己的逻辑里完全说得通，一句话能讲清
（d）第一次听说的人反应是「他疯了？」

如果你想出来的方案过不了（d），推倒重来，不要交平庸答案。

再给三样东西：
- 这个动作的真实意图（往往很小、很私人：他只是困了／他只是不想戴绿帽子）
- 它要付的代价（记进代价账：谁受损、损多少、能不能恢复）
- 一句台词：口语、反常识、最好带点不要脸或自嘲
  参考：「孤家带兵来尽孝」「父皇别跑，儿臣孝顺」「大金不做选择题」「你过河、我拆桥」
````

### 第 5 问 · 误读扩散 ★ 发散的主力

````
主角刚做的动作：{{ACTION}}
（下面每一个人都**不知道**他的真实意图。你在写他们的时候，也不许用上帝视角。）

观察者名单，以及每个人现在的处境：
{{OBSERVERS}}

对每个人输出五项：
  who       他是谁
  because   他凭什么这么想 —— 他的处境、他的知识、他吃过的亏、他此刻正在怕的事
  concludes 他得出的【错误】结论。必须比真相更大、更凶险
  acts      他因此做了什么（一个具体动作）
  spawns    这个动作制造了什么新局面

硬要求：
- 每个人的误读方向必须不同。三个人读出三个不一样的阴谋，不是同一个阴谋的三种说法
- 至少一个误读对主角有利，至少一个不利
- 至少一条要到 30 章以后才结账（写进 alive_until）
- 不许有人猜对。猜对了就没有故事了

参考（真实案例）：
  动作：赵楷在陈桥驿扎营过夜　　真实意图：他太困了，想睡一觉
  ① 崇政殿宰执｜凭「陈桥驿是太祖黄袍加身处」｜结论：他要称帝｜
     行动：集体闭嘴不敢弹劾｜生出：朝廷失去了对他的全部约束力
  ② 自己的部下｜凭同一条典故｜结论：该劝进了｜
     行动：商量去找一件黄袍｜生出：主角被吼醒，被迫当场表态并顺势整编军队
````

**第 5 问的输出里，`spawns` 最大的那一条，就是下一轮第 2 问的输入。** 循环闭合。

## 五、种子要为五个算子备什么燃料

回头看种子的八项，每一项都在给某个算子供油：

| 种子项 | 供给哪个算子 | 没有它会怎样 |
|---|---|---|
| `clock` 时钟 | 自转 | 世界不动，一切等主角，节奏死掉 |
| `shell` 壳 | 误读 | 没有身份预期，就无从「反」，也就无从被误读 |
| `counter_move` 反直觉动作 | 误读 ★ | 这是误读的**点火器**。动作越反常，误读越离谱 |
| `cheat` 方法+盲区 | 作废 | 盲区决定了每一档的解法在哪失效 |
| `prepaid_emotion` 预装情绪 | 误读 | 观察者名单就从这里来 —— 读者认识的人才值得写误读 |
| `accounts` 六本账 | 代价 | 没有账，损失无法计量，代价算子失效 |
| `volume_chain` 但是链 | 作废 ★ | 没有它就原地打转 |
| `planted_misreads` 自造误读 | 误读（复利） | 少一类可以反复提款的长期资产 |

**所以种子的八项不是「设定」，是发动机的八个进油口。** 缺一项，就有一个算子跑不动。

## 六、整体结构的优化思路

回答「整体结构有没有优化思路」。有三条，按重要性排。

### 优化一：把流水线改成循环 ★★★

现在是**流水线**：命名 → 世界观 → 总纲 → 分卷 → 阶段 → 支线 → 阶梯 → 细纲×346 → 正文×N。
一条直线，前面错了后面全错，而且前面必须在没有正文的情况下猜完全书。

应该是**一个小环 + 一根轴**：

```
        种子（八项，一次性，很短）
          │
          ▼
    ┌──► 卷要（但是链的当前一环）  ◄── 每卷重估一次
    │     │
    │     ▼
    │   【回合循环】自转 → 找矛盾 → 常规解 → 反直觉 → 误读扩散
    │     │                                        │
    │     ▼                                        │
    │   事件切章（3~25 章，一章一眼）                │
    │     │                                        │
    │     ▼                                        │
    │   逐章正文 → 验收 → 回写 world_state / misreads │
    │     │                                        │
    │     └────────────────────────────────────────┘
    │           spawns 最大的那条 = 下一回合输入
    │
    └── 账全满 & 议题到顶 → 换壳重开（算子 5）
```

**关键差别：环里的每一步都能看见已经写出来的正文。** 现在的流水线做不到 —— 它在正文存在之前就把一切排完了。

### 优化二：状态从「禁令」改成「燃料」★★★

现在 `build_context` 塞二十多个约束块，几乎全是「不得／禁止／必须衔接」。
禁令只能防倒退，不能产生推进。而且禁令一多，模型会把注意力全花在合规上，写出来的东西就是「没错，但也没意思」。

改法不是删禁令，是**换位置和换语气**：

```
提示词开头（燃料，生成式）：
  世界现在是这样：六本账 = {...}
  这些人正在这样误会主角：{...}
  这些势力刚刚各自动了：{...}
  ——> 所以接下来会发生什么？

提示词末尾（栏杆，否定式）：
  以下事实不可推翻：{...}
  以下数字已定死：{...}
```

**燃料在前，栏杆在后。** 现在是栏杆在前，燃料根本不存在。

### 优化三：验收从「打分」改成「闸门」★★

现在是写完让模型打分，低于 70 分重写 —— 模型给自己打分，天然宽松，而且分数不可行动。

应该是两道闸：
- **机器闸**（不花钱、不可争辩）：字数、对白比、问号叹号密度、段落长度、末字符是否句末标点、引号是否闭合、开场是否非主角视角。不达标直接退回，连模型都不用叫。
- **结构闸**（每回合跑一次）：这一回合是不是只动了声明的那几格账？视角有没有重复？有没有产生新误读或结掉旧误读？埋了 30 章的误读结了没有？正文和骨架冲突时有没有以正文为准回写？

`chapters/003.md` 那种断在「一个能挑两百斤担子走山路的人，七」还被标成 done 的事，机器闸第一关就拦下了。

### 附带三条小的

- **删掉 `threads.json` 的 `cadence`**。线索按日历推进是「传统」的技术根源。线索应该由误读的结账日期驱动。
- **删掉 `stages.json` 的固定 `giver/blocker/rival` 分工**。角色功能应该由「他这一回合的账」决定，能翻转。
- **`ladders` 每级加 `cost`**。没有代价的升级判不合格 —— 这一条能直接堵死「越来越强」。

## 七、一句话总结

> 种子不是提纲，是发动机的八个进油口。
> 发散不是想出更多情节，是老实结算每个人会怎么误会主角。
> 提示词的任务不是让模型**规划**，是逼它**算账**。
