# 章节名：目录是一部对手受难史

两本共 **2833 个标题**（《大宋有种》555 +《抢救大明朝》2278）全量统计。

先说最反直觉的一条：

> **目录里点对手名字的次数，是点主角名字的 1.6~2.8 倍。**

| | 点主角名 | 点对手名 | 倍数 |
|---|---|---|---|
| 抢救大明朝（2278 章） | 73（3.2%） | 206（9.0%） | **2.8×** |
| 大宋有种（555 章） | 57（10.3%） | 90（16.2%） | **1.6×** |

被点名最多的前十位，只有第三名是主角：

```
黄台吉 21  吴三桂 16  赵楷 13  崇祯 12  李自成 10
朱由检 10  史可法 9   赵桓 9    多尔衮 8  完颜亮 6
```

把目录从头读到尾，读到的是**黄台吉挺住、吴三桂什么时候死、李自成又满血了、多尔衮都哭了、大清又要完啦**。
这不是主角成长史，是**一部对手的受难史**。

原因很简单：既然每章都从别人的眼睛里看主角，标题当然是别人的名字、别人的声音。
**目录页是误读引擎在最外层的投影。**

---

## 一、标题是声轨，不是摘要

87% 的标题是"旁观陈述"句式，但它陈述的**不是作者的概括，是某个角色此刻的心声**。

| 标题 | 是谁在想／在喊 |
|---|---|
| 救命啊，遇上疯王了！ | 被赵楷冲垮的金兵 |
| 从未见过如此厚颜无耻之人！ | 被主角气到的对手 |
| 明军实在太狡猾了！ | 清军将领 |
| 这不是萨尔浒吗？ | 正在中计的多尼 |
| 爸爸，救命啊！ | 被围的完颜宗望 |
| 多铎很郁闷 | 多铎 |
| 阿玛救命，阿玛去哪儿了？ | 顺治 |
| 大清又要完啦！ | 大清的臣子 |

对照现在框架生成的：「第1章 头七夜的第一声雷」「第2章 说不通的洞」——
这是**作者站在书外给章节起的名字**。没有人在说话，目录页上一片死寂。

**判据很简单：念出这个标题，能不能听出是谁在开口？听不出就是废标题。**

## 二、八类功能（功能才是本质，模板只是壳）

| 功能 | 占比 | 例 |
|---|---|---|
| **直呼对手**（第二人称喊话） | 5.4% | 黄台吉，你要挺住啊！／吴三桂，你什么时候死？／赵楷，你的武德呢？／刁民，你们都是刁民！ |
| **不要脸／自嘲** | 3.0% | 至贱则无敌／队友就是拿来出卖的！／你过河、我拆桥／鞑子奸，我更奸！／三十六计，诈和为上 |
| **输家在喊**（求饶/挺住/救命/别哭） | 3.0% | 洪承畴，危险啊！／皇上不哭／朱纯臣都哭了／大王饶命！／王爷快跑，我掩护 |
| **军事术语＋数字** | 3.2% | 傻尼堪VS傻鞑子／五千宋军VS一万金兵／且看孤王如何八千破十万／大明万税 |
| **现代梗移植** | 2.5% | 时代变了／你们不讲武德／康熙十二时辰／爸爸去哪儿了／我来，我看，我征服／金拱门／殿试，面试 |
| **角色的错误判断** | 2.4% | 啊呀，中了圈套！／好鞑子？有古怪！／万无一失／稳坐钓鱼台／赵楷不过如此 |
| **剧透式**（把结局写进标题） | 2.2% | 李自成之死／赵佶之死／银术可已死，有事烧纸／大清亡国之日／豪格，轮到你了！ |
| **「阵营好X」反差称呼** | 0.6% | 大明好岳父／大清好女婿／满洲好兄弟／大明好债主／大宋好兄弟 |

剩下的大头是**反常识陈述句**：一声锅响，时代变了／杀身成串／男女搭配，打仗不累／不能当地主了，那就自主创业吧。

### 值得单独说的两类

**剧透式**：`李自成之死` 连着四章，`赵佶之死` 连着六章。
标题先把结果告诉你，你读的是**怎么死的、死的时候谁在场、谁因此得利**。
这是对自己叙事能力的自信 —— 悬念不在"会不会"，在"怎么会"。

**现代梗移植**：不是抖机灵，是**给读者一个已知的情绪坐标**。
「康熙十二时辰」「爸爸去哪儿了」「北洋水师！」「万里长城永不倒」—— 读者一秒钟知道这章是什么味道。

## 三、同题连章：重复本身是节奏

《抢救大明朝》有 **21 个连续同题块**，覆盖 4.2% 的章节：

```
什么？大清没了！        ×25 章（852–876，约 6.3 万字）
如何成为忠烈            ×10 章
敌在天津卫              ×7
一考订终身              ×6      炮打黄台吉  ×6
孔子保佑，刀枪不入      ×5      大清又要完啦！×5      第一帝国之兴亡 ×5
顺治大战史可法          ×4      不怕水凉高宏图 ×4      李自成之死 ×4
分田分地扎根            ×3      割地、赔款、和亲 ×3    大老虎抢亲 ×3
```

连着 25 章一个标题，本身就变成了笑话和鼓点 —— 读者翻目录看见一整屏《什么？大清没了！》，
那种滑稽和碾压感是任何单个标题都给不了的。

而这 25 章内部是**同一场战役换 25 双眼睛**：史可法 → 多铎 → 明军火枪连 → 清军巴图鲁詹岱 → 索尼 → 孝庄 → 鳌拜。

**所以同题连章不是偷懒，是「一事多章·一章一眼」在目录层的必然结果。**

## 四、形制

- 长度：均 **8.3 字**，中位 8。≤6 字 27%，7–12 字 **64%**，≥13 字 9%
- 含逗号（双句/对偶）：大宋有种 46%，抢救大明朝 31%
- **形制随格局升级**：前 1000 章是街头喊话（`大明好岳父`、`快把兵权交出来！`），
  1890 章之后切成章回体对偶：

```
朝求升，暮求合，陕西贫汉投崇祯
江南才子带路要饭，后金大汗两路来攻
崇祯帝单骑赴会，豪贝勒小心火铳
汉郡守，唐节度，明大府
```

格局越大越往史书笔法靠。这是可以做成规则的：卷次越靠后，对偶式配额越高。

## 五、写进生产线的硬规矩

```
1. 念出标题必须能听出是谁在开口。听不出，退回重起。
2. 目录里点对手名字的频次，必须高于点主角名字的频次（目标 1.5~3 倍）。
3. 禁止意象式偏正结构（「头七夜的第一声雷」「说不通的洞」这一类）。
4. 长度 6~12 字为主；≥13 字的对偶式，只在后半程放开。
5. 同一事件的连续多章，允许完全相同的标题（上限 25 章）。
6. 连续 10 章不得重复同一功能类。
7. 每 40 章至少各出现一次：剧透式、输家在喊、不要脸/自嘲、现代梗移植。
8. 主角自称（朕/孤/本宫/咱家）开口的标题控制在 6~8%，不要更多——
   主角在目录里应该是被议论的那个，不是发言的那个。
```

---

## 六、一句话

> 别给章节起名字，**给这一章配一条声轨**：让读者在目录页上听见有人在喊、在骂、在求饶、在算错。
> 而喊的那个人，多半不该是主角。
